Google My Maps 导入 route.kml · 嵌入教程（详细版）

把项目里的 route.kml 导入 Google My Maps，再把嵌入链接填进 index.html 的 MAP_CONFIG.myMapsEmbedUrl，页面就会显示 Google Maps 版路线。KML 里已按阶段分文件夹：亚洲出境、北欧·冰岛·荷兰、英伦·中欧·南欧、摩洛哥、西非、南部非洲、东非·马达加斯加、船运回国。

⚠️ 国内网络说明：google.com/maps/d/ 在中国大陆通常无法直接打开，需要先开 VPN/代理，并确保浏览器能访问 Google 账号与地图服务。若始终打不开，可改用下方「方案 B：Maps JavaScript API」（同样需要能访问 Google）。

方案 A：My Maps 嵌入（免 API Key，推荐）

  1. 准备文件：下载同目录下的 route.kml（约 50 个关键点 + 分段连线，非 GPS 级轨迹）。
  2. 打开 My Maps：VPN 开启后，用 Chrome/Edge 访问 google.com/maps/d/，登录 Google 账号。若首页空白，可试 google.com/maps/d/u/0/。
  3. 创建地图：点左上角 「+ 创建新地图」（Create a new map）。会出现「无标题地图」编辑页，左侧是图层列表。
  4. 导入 KML：
    • 在「无标题图层」下方点 「导入」（Import）。
    • 选择本机的 route.kml，或把文件拖进上传框。
    • 若弹出「选择列」对话框，一般直接 继续 即可（点坐标已在 KML 里）。
    • 导入成功后，左侧应出现多个文件夹（如「亚洲出境」「西非纵穿」等），地图上能看到彩色线与标记点。
  5. 整理（可选）：顶部把地图标题改为「克洛伊和老邓 · 570天55国」；可勾选/取消图层文件夹，隐藏不需要的段；点「预览」看最终效果。
  6. 分享权限：点 「分享」（Share）→ 在「获取链接」里把权限改为 「知道链接的任何人」可查看（Anyone with the link · Viewer）。嵌入网页必须公开可读，否则 iframe 会空白。
  7. 获取嵌入代码：
    • 仍在本地图页，点菜单 「在 My Maps 中打开」 旁的 三点 ⋮ → 选 「嵌入地图」（Embed on my site）。
    • 复制对话框里 <iframe src="..."> 中 src= 后面整段 URL（以 https://www.google.com/maps/d/embed?mid=... 开头）。
    • 示例形态：https://www.google.com/maps/d/embed?mid=1abc...xyz&ehbc=2E312F
  8. 写入网页配置：打开 index.html，找到 MAP_CONFIG，填入： 
    var MAP_CONFIG = {
  myMapsEmbedUrl: "这里粘贴上一步复制的 embed URL",
  googleMapsApiKey: ""
};
    保存后刷新本页，地图区域会显示 Google Maps iframe。

方案 B：Maps JavaScript API（支持上方「全程/亚欧/非洲」筛选）

  • 在 Google Cloud Console 创建项目 → 启用 Maps JavaScript API → 创建 API Key（建议限制 HTTP 引荐来源）。
  • 把 Key 填入 MAP_CONFIG.googleMapsApiKey，myMapsEmbedUrl 留空即可。
  • 同样需要能访问 Google；国内需 VPN。

常见问题

  • maps/d 打不开：几乎一定是网络限制，换 VPN 节点或设备再试；不要指望直连。
  • 导入时报 Anonymous uploads are not allowed：页面看起来已登录，但上传组件读不到账号（Google 已知 bug，多账号/VPN/第三方 Cookie 拦截时常见）。按顺序试：
    • 优先：走云端硬盘导入——不要点「上传」标签；先把 route.kml 传到 Google 云端硬盘，回到 My Maps 导入对话框选 「Google 云端硬盘」 标签，从 Drive 里选文件。
    • 唤醒登录态：新开标签打开 Google 表格 或 Drive，确认能正常打开后再切回 My Maps 重试导入。
    • 确认账号：点右上角头像，看当前是不是你要用的那个 Gmail；多账号时切到正确账号后刷新 My Maps。
    • 浏览器：换 Edge/Chrome 无痕窗口；暂时关闭广告拦截/隐私插件；允许 google.com 的第三方 Cookie。
    • 仍不行：清除 google.com 站点 Cookie 后重新登录，或改用下方方案 B（Maps JavaScript API）。
  • 导入后没有线：展开左侧各文件夹，勾选名为「×× 路线」的图层（眼睛图标）；若仍无线，属 My Maps 对 KML 连线的已知限制——本页已改用代码绘制连线，My Maps 仅作备份/编辑。
  • 网页 iframe 只有点没有线：My Maps 嵌入不支持可靠显示导入的 KML 折线。请留空 myMapsEmbedUrl，页面默认用 Leaflet 画线；填 googleMapsApiKey 可换 Google 底图 + 连线。

摩尔曼斯克 · 普通人追极光攻略

第 23 天 · 不需「极光猎人」几千块套餐；帖内照片均为 iPhone 14 Pro 原相机无滤镜。3 月 24 日晚首夜即追到极光（3 月底概率本不高，属幸运）。

  • 基础

    • 看到极光概率 = 极光强度（KP 值） + 云层厚度；KP 越高、云越少越好。

  • App（两个就够）

    • 极光：看 KP 值，按定位推荐观测点（看不清云层）。
    • Windy：看云层分布 ☁️；低云基本无望，高云仍有机会；选未来几小时云最少处。

  • 拍摄 & 选址

    • 极光在北面；观测点要开阔，北/西北无云无遮挡。
    • 尽量避光污染：月光、车灯都会影响；满月不宜追极光。
    • iPhone 可拍：帖内有详细参数与步骤（原帖图 4）。

环球自驾 · 车辆出入境攻略（中→哈→俄→申根）

3.1 从广州出发约一个月后抵挪威；涵盖陆路出境至首次进入申根国的车辆与口岸要求（签证攻略另帖）。

  • 🚗 中国车怎么出境

    • ATA 已停办 → 改办暂时进出境；找报关公司申报，有押金和手续费（仅担保进出中国，境外仍看各国政策）。
    • 随车证件：驾照+行驶证原件 · 英文/俄文公证翻译件 · 多语言驾照翻译小白本（支付宝，博主暂未用到）。

  • 🇰🇿 哈萨克斯坦入境

    • 海关系统与中国打通，凭中国出入境报关清单可查。
    • 填表按步查验盖章 → 获俄语通行证（哈俄条约，博主为 1 年有效期）。
    • 车辆检查较严：大件取下，引擎盖/底盘会查；保险可提前买或出境后小镇买（约 15 天一两百元）。
    • 前窗贴膜：透视度 ≥70% 即可（非完全禁止）。

  • 🇷🇺 俄罗斯入境

    • 博主经彼得罗巴甫尔关口；须贴纸签证（电子签不行）。
    • 一般顺利，但博主曾被 security 盘查约 3 小时（多国环游+法英签证记录+局势因素）。
    • 车辆保险：出发前或刚出境买均可。

  • 🇳🇴 申根国入境（挪威）

    • 芬兰关口已关闭，挪威仍可通行；政策常变，出发前可邮件咨询口岸。
    • 须申根签 + 驾照行驶证原件 + 英文公证件（证明车归属，无需报海关）。
